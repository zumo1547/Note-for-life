# Note-for-life

แอปโน้ตภาษาไทยแบบไฟล์ HTML ใช้ในเบราว์เซอร์โดยไม่ต้องติดตั้งแพ็กเกจ

## เริ่มใช้

เปิด [เว็บออนไลน์](https://zumo1547.github.io/Note-for-life/) เพื่อใช้งานทันที หรือบน Windows ให้ดับเบิลคลิก `start.cmd` แล้วเปิด `http://127.0.0.1:8765/` ในเบราว์เซอร์ (ต้องมี Node.js) หากเปิด `index.html` แบบ `file://` เบราว์เซอร์บางตัวจะบล็อกตัวอ่าน PDF แบบโมดูล

ข้อมูลโน้ตและรูปเก็บใน IndexedDB ของเบราว์เซอร์นั้น หากล้างข้อมูลเว็บไซต์หรือใช้เบราว์เซอร์อื่น ข้อมูลจะไม่ตามไปด้วย จึงควรส่งออกไฟล์สำรอง `.json` เป็นระยะ **ที่เก็บข้อมูลของ `file://` และ `http://127.0.0.1:8765/` แยกกัน** หากเคยจดในหน้าไฟล์ ให้ส่งออก JSON จากหน้าเดิมแล้วนำเข้าบนหน้าใหม่

## วิธีจด

- วางข้อความที่คัดลอกจาก PDF ลงในช่อง **เนื้อหา** ด้วย Ctrl+V ข้อความต้นฉบับจะถูกวางตามที่คลิปบอร์ดส่งมา ไม่มีขั้นตอนตัดหรือเขียนทับอัตโนมัติ
- วางรูปจากคลิปบอร์ดในช่องเนื้อหาด้วย Ctrl+V หรือกด **วางรูป** และเพิ่มรูปจากไฟล์ได้
- เลือกหรือลากไฟล์ `.txt`, `.md`, `.pdf` ลงในช่องเพิ่มไฟล์ เว็บจะเพิ่มข้อความครบและสร้างสรุปให้อัตโนมัติ ตรวจหรือแก้ต้นฉบับได้ แล้วกด **สรุปใหม่** หากต้องการ
- ไฟล์ TXT/Markdown รองรับ UTF-8, UTF-16 และภาษาไทย Windows-874/TIS-620
- PDF ที่เป็นภาพสแกนล้วนไม่มีข้อความให้ดึง แอปจะแจ้งให้ทราบแทนการเพิ่มเนื้อหาว่าง การเทียบซ้ำแบบอัตโนมัติอิงข้อความที่ตรงกัน จึงควรตรวจตัวอย่างก่อนเลือกเพิ่ม
- สรุปอัตโนมัติแบบพื้นฐานเลือกข้อความสำคัญจากต้นฉบับในเครื่อง ใช้ได้ทันที ไม่ต้องมี API key
- ดาวน์โหลดสรุปเป็น Markdown หรือ TXT, พิมพ์/บันทึก PDF, ส่งออก ZIP ที่มี Markdown และรูป, HTML ไฟล์เดียว หรือ JSON สำรองข้อมูล

## AI

หากเครื่องรองรับ WebGPU กด **ปรับสรุปด้วย AI ในเครื่อง** ครั้งแรกเบราว์เซอร์จะดาวน์โหลดโมเดล Qwen2.5 จาก Hugging Face ซึ่งใช้พื้นที่และเวลาพอสมควร ไม่มีการขอ API key และข้อความโน้ตไม่ถูกส่งไปเซิร์ฟเวอร์ โมเดลจะอ่านประเด็นที่คัดจากเอกสาร ไม่ใช่ PDF ยาวทั้งเล่ม หากเครื่องไม่รองรับ สรุปอัตโนมัติแบบพื้นฐานยังใช้งานได้

## ไฟล์

- `index.html` — หน้าจอแอป
- `styles.css` และ `typography.css` — รูปแบบหน้าจอและตัวอักษร
- `fonts/` — ฟอนต์ IBM Plex Sans Thai พร้อมสัญญาอนุญาต OFL
- `app.js` — การทำงานและที่เก็บข้อมูล
- `pdf-reader.mjs` และ `vendor/pdfjs/` — อ่านข้อความ PDF ในเครื่อง
- `local-ai.mjs` และ `vendor/webllm.mjs` — AI ที่รันในเบราว์เซอร์เมื่อเครื่องรองรับ
- `text-reader.mjs` — อ่านไฟล์ TXT ภาษาไทยหลายรูปแบบ
- `server.js` และ `start.cmd` — เปิดเว็บในเครื่องเพื่อให้เบราว์เซอร์โหลดตัวอ่าน PDF ได้
