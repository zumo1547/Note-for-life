# เล่าโน้ต

แอปโน้ตภาษาไทยแบบไฟล์ HTML ใช้ในเบราว์เซอร์โดยไม่ต้องติดตั้งแพ็กเกจ

## เริ่มใช้

บน Windows ให้ดับเบิลคลิก `start.cmd` แล้วเปิด `http://127.0.0.1:8765/` ในเบราว์เซอร์ วิธีนี้ใช้ไฟล์ PDF ได้ครบและไม่ต้องติดตั้งแพ็กเกจเพิ่ม (ต้องมี Node.js) หากเปิด `index.html` แบบ `file://` การนำเข้า TXT และรูปยังใช้ได้ แต่เบราว์เซอร์บางตัวจะบล็อกตัวอ่าน PDF แบบโมดูล

ข้อมูลโน้ตและรูปเก็บใน IndexedDB ของเบราว์เซอร์นั้น หากล้างข้อมูลเว็บไซต์หรือใช้เบราว์เซอร์อื่น ข้อมูลจะไม่ตามไปด้วย จึงควรส่งออกไฟล์สำรอง `.json` เป็นระยะ **ที่เก็บข้อมูลของ `file://` และ `http://127.0.0.1:8765/` แยกกัน** หากเคยจดในหน้าไฟล์ ให้ส่งออก JSON จากหน้าเดิมแล้วนำเข้าบนหน้าใหม่

## วิธีจด

- วางข้อความที่คัดลอกจาก PDF ลงในช่อง **เนื้อหา** ด้วย Ctrl+V ข้อความต้นฉบับจะถูกวางตามที่คลิปบอร์ดส่งมา ไม่มีขั้นตอนตัดหรือเขียนทับอัตโนมัติ
- วางรูปจากคลิปบอร์ดในช่องเนื้อหาด้วย Ctrl+V หรือกด **วางรูป** และเพิ่มรูปจากไฟล์ได้
- เลือกหรือลากไฟล์ `.txt`, `.md`, `.pdf` ลงในพื้นที่ **นำเข้าและเทียบข้อมูล** แอปจะอ่านไฟล์ เทียบกับเนื้อหาโน้ตเดิม และแสดงจำนวนบรรทัดใหม่/ซ้ำพร้อมตัวอย่างก่อนเพิ่มจริง เลือกเพิ่มเฉพาะข้อมูลใหม่หรือเพิ่มทั้งหมดได้
- หากเชื่อม AI ไว้ แอปจะวิเคราะห์ไฟล์ที่นำเข้าโดยอัตโนมัติ TXT/Markdown จะมีสรุปเบื้องต้น ส่วน PDF จะมีการเทียบข้อมูลและประเด็นที่อาจขัดแย้ง การวิเคราะห์เป็นตัวอย่างแยกจากเนื้อหาโน้ต PDF จะไม่ถูกสรุปเป็นสรุปสุดท้ายจนกว่าจะกด **สรุปประเด็น** หลังเพิ่มข้อมูล
- PDF ที่เป็นภาพสแกนล้วนไม่มีข้อความให้ดึง แอปจะแจ้งให้ทราบแทนการเพิ่มเนื้อหาว่าง การเทียบซ้ำแบบอัตโนมัติอิงข้อความที่ตรงกัน จึงควรตรวจตัวอย่างก่อนเลือกเพิ่ม
- **จัดบรรทัด PDF**, **ร่างหัวข้อ**, และ **สรุปประเด็น** แสดงผลแยกจากต้นฉบับ กดใช้ผลลัพธ์จึงจะสร้างโน้ตใหม่หรือเพิ่มเป็นสรุป
- ส่งออกเป็น ZIP ที่มี Markdown และรูป, HTML ไฟล์เดียว, TXT สรุป, JSON สำรองข้อมูล หรือพิมพ์เป็น PDF ผ่านเบราว์เซอร์

## AI

กดปุ่มเฟืองแล้วกรอก HTTPS endpoint ที่รองรับ Chat Completions, ชื่อโมเดล และ API key คีย์อยู่ในหน่วยความจำของหน้าเว็บเท่านั้น เมื่อปิดหรือโหลดหน้าใหม่ต้องกรอกอีกครั้ง การใช้ AI จะส่งข้อความโน้ตหรือไฟล์ที่นำเข้าไปยัง endpoint ที่ระบุ โปรดใช้บริการที่คุณไว้ใจ บริการนั้นต้องรองรับคำขอจากเบราว์เซอร์ (CORS)

หากไม่ได้เชื่อม AI ปุ่มร่างหัวข้อและสรุปประเด็นจะใช้วิธีดึงข้อความสำคัญในเครื่องแทน ปุ่มต่อยอดไอเดียต้องเชื่อม AI

## ไฟล์

- `index.html` — หน้าจอแอป
- `styles.css` — รูปแบบหน้าจอ
- `app.js` — การทำงานและที่เก็บข้อมูล
- `pdf-reader.mjs` และ `vendor/pdfjs/` — อ่านข้อความ PDF ในเครื่อง
- `server.js` และ `start.cmd` — เปิดเว็บในเครื่องเพื่อให้เบราว์เซอร์โหลดตัวอ่าน PDF ได้
